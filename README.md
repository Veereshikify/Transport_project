# Transport Management System 🚍

A web-based Transport Management System built using **Flask** and **MySQL** to manage transport operations such as buses, employees, complaints, and daily activities with basic AI-supported features.

---

## 📌 Problem Statement
Managing transport operations manually leads to data inconsistency, delays, and poor tracking of buses, employees, and complaints. There is a need for a centralized digital system to efficiently manage transport-related data and operations.

---

## 💡 Solution
This project provides a centralized **Transport Management System** that allows administrators to:
- Manage buses and transport staff
- Handle user complaints
- Track daily transport activities
- Generate PDF reports
- Improve efficiency using automation and AI-supported logic

---

## ✨ Features
- Admin dashboard
- Bus management
- Employee management
- Complaint management
- PDF report generation
- Secure login system
- Web-based interface using Flask
- Database integration with MySQL

---

## 🛠 Tech Stack
- **Backend:** Python (Flask)
- **Frontend:** HTML, CSS, Bootstrap
- **Database:** MySQL
- **Libraries:**  
  - Flask  
  - mysql-connector-python  
  - reportlab
